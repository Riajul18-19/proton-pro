# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.3.x   | :white_check_mark: |
| < 1.3.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within Proton PRO, please send an email or submit a private security advisory on GitHub.

Please include:
- Description of the vulnerability
- Proof-of-concept steps to reproduce
- Potential impact

We take all security reports seriously and will respond promptly.
