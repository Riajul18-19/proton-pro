# Contributing to Proton PRO

Thank you for your interest in contributing to Proton PRO! 🛡️

## Code of Conduct
We are committed to providing an open, welcoming, and harassment-free environment for everyone.

## Development Setup
1. Clone this repository:
   ```bash
   git clone https://github.com/Riajul18-19/proton-pro.git
   cd proton-pro
   ```
2. Validate project configuration:
   ```bash
   npm test
   ```
3. Load the unpacked extension in Chrome:
   - Navigate to `chrome://extensions`
   - Enable **Developer Mode**
   - Click **Load unpacked** and select the `Proton PRO` directory

## Submitting Pull Requests
1. Fork the repository.
2. Create your feature branch (`git checkout -b feature/amazing-feature`).
3. Commit your changes (`git commit -m 'feat: add amazing feature'`).
4. Push to your branch (`git push origin feature/amazing-feature`).
5. Open a Pull Request with detailed description and screenshots.
