# Changelog

All notable changes to **Proton PRO** will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

---

## [1.3.6] - 2026-11-01

### Added
- ⚡ **Manifest V3 Service Worker**: Full migration to modern Chrome Manifest V3 standard with lightweight background service worker.
- 🛡️ **WebRTC & IPv6 Leak Shields**: Active browser-level leak prevention policies.
- 🌐 **35+ International Languages**: Multi-language localization including Arabic, Chinese, French, German, Spanish, Japanese, and more.
- 🚀 **Automated CI/CD Release Pipeline**: GitHub Actions workflows for automated package creation, checksum verification, and release deployment.
- 🎨 **Animated Cyber Visuals**: Embedded dynamic SVG headers, live status consoles, and feature matrices.

### Changed
- Improved connection handshake speed and memory efficiency.
- Refined popup UI with high-DPI icons and modern dark cyber styling.

### Security
- Verified zero-logs routing architecture.
- Enforced strict Content Security Policy (`script-src 'self'`).
